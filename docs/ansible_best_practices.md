| Functionality / Purpose                      | Recommended Tool                                  | What It Does                                                                                                       |
| -------------------------------------------- | ------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------ |
| Python environment and dependency management | **uv**                                            | Creates the virtual environment, installs Python dependencies, and maintains a lock file.                          |
| Ansible runtime                              | **ansible-core**                                  | Provides `ansible`, `ansible-playbook`, inventory handling, modules, and core execution.                           |
| Ansible static analysis                      | **ansible-lint**                                  | Checks Ansible-specific quality, correctness, naming, FQCN usage, risky commands, and common idempotence problems. |
| General YAML linting                         | **yamllint**                                      | Checks YAML syntax, indentation, formatting, line length, and document structure.                                  |
| Local Git hooks                              | **pre-commit**                                    | Automatically runs linting, formatting, secret detection, and file checks before commits.                          |
| Playbook syntax validation                   | **ansible-playbook --syntax-check**               | Confirms that playbooks parse correctly without executing them.                                                    |
| Role integration testing                     | **Molecule**                                      | Creates disposable test systems, applies roles, verifies results, and destroys the environment.                    |
| Test target provisioning                     | **Docker**                                        | Provides disposable Linux containers for Molecule tests.                                                           |
| Python unit testing                          | **pytest**                                        | Tests custom modules, plugins, filters, inventory code, and Python helper functions.                               |
| Python code coverage                         | **pytest-cov / coverage.py**                      | Measures statement and branch coverage for Python code.                                                            |
| Ansible collection testing                   | **ansible-test**                                  | Runs sanity, unit, and integration tests for collections, modules, and plugins.                                    |
| Version compatibility matrix                 | **tox-ansible**                                   | Tests against multiple Python and `ansible-core` versions.                                                         |
| Reproducible Ansible runtime image           | **Ansible Builder**                               | Builds containerized Ansible Execution Environments.                                                               |
| Running Execution Environments               | **ansible-navigator**                             | Runs playbooks inside Execution Environment containers.                                                            |
| Developer command interface                  | **Make** / **Makefile**                           | Provides consistent commands such as `make lint`, `make test`, and `make check`.                                   |
| CI automation                                | **GitHub Actions**                                | Runs linting and tests automatically for pushes and pull requests.                                                 |
| Secret scanning                              | **Gitleaks**                                      | Detects passwords, tokens, keys, and other secrets accidentally committed to Git.                                  |
| Ansible dependency installation              | **ansible-galaxy**                                | Installs roles and collections listed in `requirements.yml`.                                                       |
| Dependency update automation                 | **Renovate**                                      | Opens automated pull requests when dependencies have updates.                                                      |
| Role input validation                        | **argument_specs.yml**                            | Defines and validates expected role variables, types, choices, and required values.                                |
| Check-mode testing                           | **ansible-playbook --check --diff**               | Predicts changes and displays configuration differences without applying them.                                     |
| Idempotence testing                          | **Molecule idempotence**                          | Runs the role again and verifies that no unnecessary changes occur.                                                |
